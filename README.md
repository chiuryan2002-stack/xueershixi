# 學而時習｜原、前、舊、老 華語辨析 App

網址：https://chiuryan2002-stack.github.io/xueershixi/
研究網站：https://chiuryan2002-stack.github.io/yqjl-bert/

可安裝的網頁 App（PWA）：用手機開啟網址，選「加入主畫面」，沒有網路也能練習。

## 題庫

全部 96 題都是完整句子，句中都有決定答案的線索；每題附解析與英譯，有些題另外接受第二個答案（會說明哪個最自然）。

| 級別 | 線索 | 題數 |
|---|---|---|
| 初級（CEFR A1–A2） | 常用詞，線索直接寫在句子裡：以前、現在、已經、二十年 | 32（每字 8 題） |
| 中級（CEFR B1–B2） | 從情境推論：升官、併購、懷念、資歷 | 32（每字 8 題） |
| 高級（CEFR C1–C2） | 語域、評價與陷阱：公文、續任、倚老賣老、調離原職 | 32（每字 8 題） |

分級標準：Common European Framework of Reference for Languages（CEFR）歐洲語言共同參考架構。

題目原稿在 `learn_bank.py`（方便檢閱與修改；網站實際讀取的是由它產生的 `learn_data.js`）。

## 身分與分頁

第一次開啟會依序設定：身分（華語教師／華語為二語學習者／華語為母語者）→ 程度（CEFR A1–C2；母語者略過）→ 國籍 → 母語 → 名字。之後可在「我的」修改。

- 學習端（二語學習者、母語者）：今日、練習、複習、錯題本、語義眼鏡、實驗室、我的
- 教師端：班級後台（可依程度、母語篩選，並比較各母語群的混淆）、題庫講義（下載題目卷＋答案卷）、練習、語義眼鏡、實驗室、我的

## 語義眼鏡

在任何網頁標出「原、前、舊、老＋職場身分名詞」，滑鼠移上去看字義與句中線索。三種用法：Chrome／Edge 擴充功能（`yqjl-glasses.zip`）、書籤小工具（App 內「語義眼鏡」頁可拖曳）、手機直接在 App 內貼上文章。全部在本機執行，不上傳資料。

## 舊版分頁說明

今日（每日一題、連續天數、掌握度）、練習（三級＋四組混淆特訓＋重練錯題）、複習（萊特納盒間隔複習）、錯題本（混淆矩陣）、我的（多位學習者、徽章、排行榜、學習代碼、每日提醒）、教師（匯入全班紀錄、CSV）、實驗室（瀏覽器內的 Chinese BERT-base）。

資料只存在使用者的瀏覽器。改網址：修改 `site.js` 裡的 `YQ_WEB_URL`、`YQ_APP_URL` 兩行。
