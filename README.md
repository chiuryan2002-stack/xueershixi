# 學而時習｜原、前、舊、老 華語辨析 App

網址：https://chiuryan2002-stack.github.io/xueershixi/
研究網站：https://chiuryan2002-stack.github.io/yqjl-bert/

可安裝的網頁 App（PWA）：用手機開啟網址，選「加入主畫面」，沒有網路也能練習。

## 題庫

全部 96 題都是完整句子，句中都有決定答案的線索；每題附解析與英譯，有些題另外接受第二個答案（會說明哪個最自然）。

| 級別 | 線索 | 題數 |
|---|---|---|
| 初級（A2–B1） | 直接寫在句子裡：離職、二十年、至今、卸任 | 32（每字 8 題） |
| 中級（B1–B2） | 從情境推論：升官、併購、懷念、資歷 | 32（每字 8 題） |
| 高級（C1） | 語域、評價與陷阱：公文、續任、倚老賣老、調離原職 | 32（每字 8 題） |

題目原稿在 `learn_bank.py`（方便檢閱與修改；網站實際讀取的是由它產生的 `learn_data.js`）。

## 分頁

今日（每日一題、連續天數、掌握度）、練習（三級＋四組混淆特訓＋重練錯題）、複習（萊特納盒間隔複習）、錯題本（混淆矩陣）、我的（多位學習者、徽章、排行榜、學習代碼、每日提醒）、教師（匯入全班紀錄、CSV）、實驗室（瀏覽器內的 Chinese BERT-base）。

資料只存在使用者的瀏覽器。改網址：修改 `site.js` 裡的 `YQ_WEB_URL`、`YQ_APP_URL` 兩行。
